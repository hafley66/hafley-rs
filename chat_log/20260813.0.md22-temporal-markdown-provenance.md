## Problem/Context
Original temporal formula:

```text
agent message(T-1)
  -> filesystem/git state(T)
  -> markdown revision M(T,V)
  -> diff M(T,V-1 -> V)
```

Need direct provenance when available and evidence-scored association otherwise. Git commits do not describe dirty, staged, or untracked worktree state. Worktree revisions must remain readable after later edits.

## Solution/Approach
Pipeline boundary:

```text
markdown bytes
  -> parser adapter
  -> markdown events/CST facts
  -> fact extractors
  -> identity reconciliation
  -> graph facts/transforms
  -> D2 projection
```

Reuse:
- `soopy`: repository discovery, `RepositoryId`, `RevisionId`, `SourceRef`, git blob/BLAKE3 `ContentId`, revision-pinned snapshots, git batch reads, watched `SourceDelta` values.
- `sprefa-extract`: pure per-content extraction, flat JSONL fact wire, source roster, revision-pinned `SourceTreeBlobSource` adapter.
- sprefa engine: separate engine `tick` and git `rev`, signed delta history and retractions.
- boop: sessions, messages, tool calls, cwd, temporal ordering, traces.

Association evidence classes: captured repository state, exact tool write, exact patch overlap, copied block overlap, path/repository match, temporal proximity, and competing-writer penalty. Store evidence components rather than only a score.

## Key Insights
- Current `RevisionId::Worktree { head, dirty }` aliases every dirty state beneath the same HEAD; file `ContentId` distinguishes files but does not identify the complete worktree snapshot.
- Current `SourceDelta::Changed` retains the old content id but not old worktree bytes; reading the old path after mutation fails expected-content validation.
- tree-sitter-md was already a dependency and query grammar before MarkdownSource routing existed.
- MarkdownSource follows surrounding code by emitting the existing `CstF` plane rather than introducing a document-specific family prematurely.
- Inline markdown must be parsed separately and its byte spans offset into the owning block grammar `inline` region.
- Directly captured causal edges and inferred edges should use the same shape with different basis/evidence fields.
