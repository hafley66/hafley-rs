## Solution/Approach
- **`cli.yaml`** 3718 lines, real OpenAPI 3.1 `paths`. 113 operations, 48 positionals, 284 options. Every clap `about` and arg help verbatim. Source is the installed binary's `--help` per path, not main.rs. Required positionals go in the URL template, optional ones become `in: query`. Responses `"200"`/`"400"` carry `x-exit-code` 0/2.
- **`relational.yaml`** 791 lines, 69 tables, 307 columns, 29 dicts. JSON Schema 3.1 (`type: [integer, "null"]`, NOT `nullable:`). `x-boop-defect` fires when a column declares `x-dict` but is not an integer.
- **`queries.yaml`** 327 statements, 157 with typed output columns. Output columns come from **sqlite preparing the statement** (bind every `?` to NULL, wrap in `LIMIT 0`, read `cursor.description`), which is why `SELECT *` and `COALESCE(...)` aliases resolve. `x-sql-class: dql|dml|ddl|pragma` + tags. Method by class; `INSERT OR IGNORE` earns `put`, bare `INSERT` gets `post`.
- **`sql.yaml`** 373 sites by verb, **`env.yaml`** 29 names, **`crates.yaml`** 8 crates + effects, **`clusters.yaml`** CRUD per table, **`er.d2`** family -> dict ER board.
- **Type graph**: `crates/boop/scripts/typegraph-d2.sh`, 6 stages, `extract --family cst --sqlite` -> sqlite tiers -> awk -> d2. 340 types, 242 edges, max tier 5. **420 SCCs, all singletons: the type graph is a DAG, SCC gives no partition.** WCC does: 137/39/11/7/17 small/182 isolated.

## Key Insights
- **I burned 26 GB of the user's RAM.** `typegraph.py` keyed a CST parent/child map by span tuple. A CST routinely has distinct nodes with identical extents (`expression_statement` wrapping its expression), so both collapse to one key, a node becomes its own child, and the walk never terminates. Deleted. The sqlite route (span containment, `r.span__start>=d.s AND r.span__end<=d.e`) has no parent map and no cycle.
- **I fabricated `/agent_turn/3a0d61f2` as a "real" example and it was not in the file.** Caught only because the user asked what the hash was. Hashes are `blake2s(normalize_ws(sql), digest_size=4)`.
- **d2 tier containers were the render bug, not the file.** Containers made elk reserve routing gutters: empty black boxes + canvas-length edge detours. 4518x6728 aspect 0.67 -> **2423x1662 aspect 1.46** by deleting them. The engine's own ranks already ARE the tiers.
- **An apostrophe inside a single-quoted awk program terminates it.** `# the DAG's own ranks` broke the script.
- **`agent_route.session_id` is TEXT; the other 16 are INTEGER.** `JOIN dict_session ON d.id = r.session_id` -> **0 rows**. `ON d.value` -> **163 of 166**. Wrong answer, no error.
- **`dict_record`: 538,548 of 539,358 rows unreferenced (99%), 23.5 MB.** Only reader is `sync_cursor.record_id_id`, which uses 812 distinct ids.
- **`dict_request` is not a dict.** `(id, message_id, request_id)`, no `value`, 516,925 rows, 27.6 MB. The other 28 are all `(id, value)`.
- **Three spellings of one FK**: `<stem>_id`, `<stem>_ref` (`agent_usage.request_ref`), `<stem>_id_id` (`sync_cursor.record_id_id`), plus prefixed (`agent_live.tmux_pane_id`). A convention-based reader misses the two largest dicts; they sat in an "orphan" bucket of 1,057,024 rows until the classifier learned all three, then orphans fell to 791.
- **40 unindexed FKs** incl. `agent_turn.role_id` and `.cwd_id` on 1,022,170 rows. Interning exists to make joins integer compares; no index gives the cost back.
- **3 of 69 tables support full CRUD.** 25 are `CR` only.
- **Zero schemaless storage.** `agent_session_attr` has had 2 keys ever (`effort` 83, `reset_ts` 1); `agent_trace_event.detail` is the same 6 fields every row, and that detail column IS the invocation analytics I re-derived by hand from 2,963 arglines.
- Cleared: 0 dangling FKs across 55 columns, 0 epoch unit mismatches, 0 dicts missing UNIQUE, 0 tables without a PK.
- `ast-grep` is NOT installed anywhere on this machine. User chose `sprefa-extract` instead.
- `extract --family cst --sqlite` did 147 files / 1,030,116 rows in **2.5s**. The python equivalent ran 6 minutes and then ate the box.
- `@terrastruct/d2` wasm is `v0.7.0-HEAD` vs CLI `v0.7.1`; it returns `layers=1` on a two-board file and drops the second silently. `d2.ts:31` also overrides `themeID` with `d2ThemeId(dark)` (dark=200, light=8).
- instant DOES open a bare `.d2` on cmd-click. My claim that it only handles ```d2 fences was wrong.
