## Facts about the new predicates

- `#nth-child? @c "N"` 1-based, `An+B` accepted, optional label = ofRule, optional `"reverse"`. Arity 2..=4.
- `#range? @c "line:col" "line:col"` zero-based, EXACT node start and end (ast-grep's `RangeMatcher` compares both endpoints; it is not a window). Arity 3.
- `#pattern? @c "$A.x()" A label [B label2 ...]`: trailing pairs become `constraints: {A: {matches: label}}`; keyed per file; same metavar to two labels = `ConstraintConflict`. Arity even, >= 2.
- `AstRuleRequest.constraints` serializes with `skip_serializing_if = Vec::is_empty` so `tests/fixtures/source_facts/1_expected.json` stays byte-identical.
- The snapshot `tests/fixtures/scm/lower.snap` was regenerated; census now lists 13 `AstRule` variants and 9 `ScmLowerError` variants, all reached.
