## Key Insights
- tauri-plugin-opener `is_path_allowed` = fs scope built from the permission's own `allow` entries AND an entry matching the app; no entries means every path is refused. `requireLiteralLeadingDot` defaults true on unix, so `/**` skips dot dirs.
- The pane's `pane_current_path` is the shell's cwd, not the agent's per-command cwd; agent output paths are relative to whatever the agent `cd`'d into. `agent_touch` (98k rows) is the source that knows.
- A pty never carries an image; claude/codex read the OS pasteboard on their paste key. Put the file on the pasteboard, press the key.
- boop's session graph (`load_agent_session_graph_with_runtime`) is the nesting source; `agent_route` is a registry.
- `git merge` onto a detached HEAD fast-forwards HEAD, not the branch; check `git status -sb` before merging into someone's daily-driver checkout.
- Native opus subagent flow works: `boop beep agent register <name> --parent claude-498`, Agent tool model opus, `agent done` now walks the ladder and lands in the coordinator's door.
